# E-commerce-customer-churn-analysis
# E-Commerce Customer Churn Analysis & Prediction

**A Machine Learning Project | Business Data Mining | Tunis Business School**

## Project Overview

Customer retention is a major challenge for e-commerce businesses. This project investigates customer churn patterns and applies machine learning classification techniques to identify customers who are more likely to leave.

Using a dataset of **5,630 customer records and 20 explanatory features**, the project combines exploratory data analysis, data preprocessing, predictive modelling and business interpretation to generate actionable customer retention insights.

## Objectives

- Explore customer behaviour and identify churn patterns.
- Understand the factors associated with customer churn.
- Build and compare machine learning classification models.
- Translate analytical findings into practical customer retention recommendations.

## Tools & Technologies

- **Programming:** Python
- **Data Analysis:** pandas, NumPy
- **Visualization:** Matplotlib, Seaborn
- **Machine Learning:** scikit-learn
- **Methods:** Exploratory Data Analysis, Feature Engineering, Classification, Hyperparameter Tuning, Model Evaluation

## Methodology

1. **Data Exploration:** Examined customer characteristics, churn distribution and relationships between variables.
2. **Data Preprocessing:** Prepared the dataset for modelling, including handling missing values and encoding categorical variables.
3. **Model Development:** Developed and compared four classification algorithms:
   - Logistic Regression
   - Decision Tree
   - Random Forest
   - Gradient Boosting
4. **Model Evaluation:** Used train/test splitting, cross-validation, GridSearchCV and evaluation metrics including ROC-AUC, F1-score, precision and recall.
5. **Business Interpretation:** Examined important churn indicators and translated the findings into customer retention recommendations.

## Key Findings

The analysis highlighted three important indicators associated with customer churn:

- **Customer Tenure:** Customers with shorter relationships with the business showed a greater tendency to churn.
- **Customer Complaints:** Customers who submitted complaints were more likely to leave.
- **Cashback Amount:** Lower cashback amounts were associated with higher churn.

## Business Recommendations

The findings were translated into seven customer retention recommendations, including:

- Introducing a structured 90-day onboarding program for new customers.
- Improving complaint handling and resolution processes.
- Designing targeted cashback campaigns.
- Strengthening customer engagement and retention initiatives.

## Project Limitations

The dataset is observational, so the identified relationships should be interpreted as associations rather than proof of causation. The churn classes were also imbalanced, which is an important consideration when interpreting model performance.
